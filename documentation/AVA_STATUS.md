# Ava Status

This is the implementation truth table. It should be updated when code changes, while `AVA_DESIGN.md` stays mostly stable.

Last code check: 2026-07-25.

Status vocabulary:

- Built: implemented in code and part of the normal path.
- Partial: implemented but limited, gated, fragile, or not yet proven enough to treat as finished.
- Logged-only: code records data but does not change live behavior.
- Pending: design exists, but no meaningful implementation yet.
- Removed: implementation existed or was planned, but is intentionally absent now.

| Per-exchange retrieval anchors (descriptor + tags) | **Built (2026-07-29) — producer + query side + a live RETRIEVAL CHANNEL with its own reserved slot.** **Retrieval channel (2026-07-29):** anchors are wired into `rag_engine` as a fourth FAISS index with one reserved slot (`_ANCHOR_TOP_K`=1) inside the past-chat block. The framing that settled the design: an anchor is not a fourth kind of memory but the **exchange-granular counterpart of the gist**, which is session-granular — verbatim dies hard at `rag_cap_age_h`, after which a whole conversation is one session recap forever, and the anchor is what keeps a *specific* exchange recallable past that cap.
